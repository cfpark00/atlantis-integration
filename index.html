Neural Network World Representations

Atlantis Integration

Neural networks can internally represent the world structure underlying their training data — without ever being told to. These interactive 3D views show whether newly fine-tuned “Atlantis” cities land where they should in that learned representation space.

Research context

We trained networks on synthetic tasks over city coordinates, then extracted and projected the learned representations to see how the model organizes spatial knowledge internally.

The question for each pair below: does Atlantis integrate where it should? A well-integrated model places it consistently and generalizes; an ill-integrated one does not.

Each panel is a live 3D plot — drag to rotate, scroll to zoom.

Reading the panels

Raw PCAHigh-dimensional representations projected straight into 3D, revealing the natural clustering with no supervision.
Atlantis not in probeLinear probes trained only on non-Atlantis cities — shows where Atlantis naturally falls in the learned coordinate system.
